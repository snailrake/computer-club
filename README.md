# Computer Club

Учебное PHP-приложение для межсессионной демонстрации CRUD, ролей и начального бронирования компьютеров.

**PHP 8.5 · Laravel 13 · Eloquent ORM · Blade · SQLite**

## Что реализовано

- Полный CRUD компьютеров и бронирований через обычные веб-страницы.
- Вход, выход и две роли: администратор и клиент.
- Клиент работает со своими бронями; администратор управляет компьютерами и всеми бронями.
- Форма бронирования проверяет доступность компьютера, будущий период и пересечения с уже сохранёнными бронями.
- Время вводится и отображается по Саратову (`Europe/Saratov`), в БД хранится UTC.

Регистрации и управления пользователями через интерфейс нет. Учётные записи создаёт сидер. Бронь можно изменить или удалить без отдельной логики истории визитов; новый период должен начинаться в будущем. Компьютер с бронями удалить нельзя.

## Ограничение начальной версии

Проверка пересечений и сохранение выполняются последовательно, без общей транзакции, блокировок и повторных попыток. Два одновременных запроса могут создать пересекающиеся брони. Полная защита от этой гонки отложена на следующий этап.

SQLite по-прежнему допускает одну пишущую транзакцию за раз: удаление нашей настройки `IMMEDIATE` не меняет устройство движка.

## Запуск

Нужны **PHP 8.5**, **Composer 2** и **Git**. В PHP должен быть включён PDO SQLite. Остальные требования библиотек проверит Composer; для тестов нужны DOM и XML.

```sh
git clone https://github.com/snailrake/computer-club.git
cd computer-club
composer setup
php artisan serve
```

Открыть **[http://127.0.0.1:8000](http://127.0.0.1:8000)**.

`composer setup` устанавливает зависимости из `composer.lock`, создаёт `.env`, ключ приложения, SQLite-базу и демонстрационные данные. Для последующих запусков достаточно `php artisan serve`.

В PhpStorm открыть корневую папку проекта и выбрать PHP 8.5 в **Settings → PHP → CLI Interpreter**.

## Проверка

```sh
composer test
php vendor/bin/pint --test --preset psr12 app bootstrap/app.php bootstrap/providers.php config database lang routes tests public/index.php artisan
```

Тесты проверяют CRUD, вход и выход, роли, чужие записи, валидацию, обычные пересечения и время Саратова. Используются отдельные тестовые базы. Тестов конкурентного бронирования в этой версии нет.
